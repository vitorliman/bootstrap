SOBRE O FRAMEWORK

O que é Bootstrap?

Bootstrap é um framework front-end que reúne componentes e classes prontas para ajudar no desenvolvimento de páginas web.

Em vez de criar tudo do zero, podemos usar recursos como botões, cards, menus, formulários e o sistema de Grid. Assim, fica mais fácil organizar o site e fazer com que ele funcione em diferentes tamanhos de tela.
